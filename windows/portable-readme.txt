Videoport для Windows 11 x64

1. Распакуйте ZIP целиком.
2. Откройте Videoport.exe внутри распакованной папки.
3. Выберите вкладку YouTube, Instagram или TikTok, вставьте ссылку и нажмите «Найти материалы».
4. Выберите материалы и качество. Нажмите «Скачать выбранные» или «Скачать все».

Файлы сохраняются в папке «Загрузки\Videoport». Выберите другую папку для каждой площадки в нижней панели.
«Пакетная загрузка» принимает несколько ссылок, каждую с новой строки.
Для сторис, хайлайтов и профиля Instagram при необходимости включите вход из Firefox.
Окно «Загрузки» показывает ход задач и скачанные файлы. Там можно поставить
задачу на паузу, возобновить или отменить её, открыть файл и папку.
По умолчанию видео сохраняется в MKV без перекодирования.
Если закрыть окно во время загрузки, программа закончит её в фоне.

Окно использует Microsoft Edge WebView2 из стандартной Windows 11.
Все остальные компоненты уже находятся рядом с Videoport.exe.
Первый запуск может занять несколько секунд, пока распаковывается FFmpeg.
Программа собирается без Authenticode-подписи. Исходный код доступен на GitHub.

https://github.com/Poklontsevv/downloader

«Нарезка» предлагает клипы по речи, движению и сменам сцен.
Можно поправить границы и субтитры, посмотреть превью и экспортировать MP4 9:16.
Whisper скачивает модель около 60 МБ. Смысловой анализ Qwen потребует ещё около 1,15 ГБ.
Видео обрабатывается на компьютере.

Установка и обновление доступны через отдельный Videoport-Setup. В нём можно выбрать папку программы.
Установщик скачивает Qwen и llama.cpp в подпапку models.
Чтобы обновиться, закройте программу и запустите Setup новой версии.

# Videoport

Скачивайте свои видео и обложки с YouTube в папку на компьютере. Можно вставить несколько ссылок, настроить разрешение каждого ролика и запустить пакетную выгрузку для дальнейшей публикации в Рутубе, Дзене и ВК.

- Обычные ссылки, Shorts и записи завершённых эфиров.
- Разрешения из списка YouTube, включая вертикальное видео, 4K или 8K при наличии.
- MP4 с H.264 и AAC для публикации. Совместимые дорожки копируются, остальные перекодируются через FFmpeg.
- MKV с исходными дорожками без перекодирования.
- Обложки отдельно или вместе с видео. Сохраняется исходный формат изображения.
- Заголовок ролика используется как имя файла. Запрещённые символы удаляются, слишком длинные имена сокращаются, системные имена Windows получают префикс `_`. При совпадении имён добавляется номер.

## Windows 11

Распакуйте портативный ZIP для Windows 11 x64 целиком и откройте `Videoport.exe` внутри папки. Программа откроет своё окно. Вставьте ссылку, нажмите **Найти видео**, выберите разрешение и нажмите **Скачать видео** или **Скачать обложку**.

Готовые файлы сохраняются в папке `Загрузки\Videoport`. Кнопка **Открыть папку загрузок** открывает её в Проводнике. Для нескольких ссылок используйте **Пакетная загрузка**.

В ZIP входят Python, FFmpeg, Node.js и зависимости. Окно использует Microsoft Edge WebView2, который поставляется с Windows 11.

### Каналы, профили и очереди

- **YouTube:** вставьте ссылку на канал или отдельный ролик. Каталог показывает доступные видео, Shorts и записи эфиров.
- **Instagram:** вставьте ссылку на рилс, сторис, хайлайт или профиль. Для каталога рилсов, актуальных сторис и хайлайтов из профиля войдите в Instagram в Firefox и включите **Использовать вход из Firefox** на вкладке. Материалы доступны в пределах прав этой учётной записи.
- **TikTok:** вставьте ссылку на профиль или отдельное видео.

В списке отметьте нужные материалы. Кнопка **Показать варианты** запрашивает точные разрешения. По умолчанию скачивается лучшее доступное качество. Нижняя панель **Скачать все** выгружает текущий список, а **Скачать выбранные** — отмеченные строки. Через **Выбрать папку** можно сохранить отдельный путь для каждой площадки.

## Локальный запуск

Установите [Python 3.10+](https://www.python.org/downloads/), [FFmpeg](https://ffmpeg.org/download.html) с FFprobe и libx264, а также [Node.js 22+](https://nodejs.org/en/download) или [Deno 2.3+](https://deno.com/). Команды `ffmpeg`, `ffprobe` и выбранная среда JavaScript должны быть доступны в терминале.

```sh
git clone https://github.com/Poklontsevv/downloader.git
cd downloader
python -m venv .venv
```

Активируйте окружение. На macOS и Linux используйте `source .venv/bin/activate`, в Windows PowerShell — `.\.venv\Scripts\Activate.ps1`. Если в вашей системе Python запускается как `python3` или `py`, используйте эту команду для создания окружения.

```sh
python -m pip install -r requirements.txt
python -m videoport
```

Откройте [локальный интерфейс](http://127.0.0.1:8765). Вставьте ссылки по одной на строку, выберите разрешения и нажмите **Скачать выбранные**. Обложку можно скачать кнопкой на карточке ролика или у всех выбранных роликов сразу. Файлы появятся в папке `downloads`. Очередь сохраняется до остановки программы.

Параметры запуска:

```sh
python -m videoport --output "./exports"
python -m videoport --js-runtime deno
python -m videoport --browser firefox
```

Для закрытых видео запустите Videoport с `--browser` и укажите браузер, в котором открыт YouTube под аккаунтом с доступом к ролику. При ошибке чтения профиля закройте браузер и повторите попытку. Можно использовать локальную страницу Videoport в другом браузере. Хромиум-браузеры в некоторых конфигурациях шифруют cookies и ограничивают их чтение, в этом случае подойдёт Firefox с открытым сеансом YouTube.

## GitHub Pages

Откройте [Videoport на GitHub Pages](https://poklontsevv.github.io/downloader/) и запустите загрузчик на том же компьютере:

```sh
python -m videoport --allow-pages
```

Нажмите **Подключить** и разрешите браузеру доступ к локальной сети, если он запросит разрешение. GitHub Pages обслуживает интерфейс, а yt-dlp и FFmpeg работают локально. Если браузер блокирует подключение страницы к локальной сети, откройте [локальный интерфейс](http://127.0.0.1:8765).

## Доступность видео

Качество зависит от дорожек, которые YouTube отдаёт для ролика. Обновляйте yt-dlp, если YouTube поменял способ выдачи видео.

```sh
python -m pip install -U -r requirements.txt
```

## Videoport 4.8.2 для Windows 11 x64

Запустите установщик и выберите прежнюю папку Videoport для обновления.

- Во время фоновой работы окно Videoport можно вернуть ярлыком или значком рядом с часами.
- При повторном открытии сохраняются текущий экран и задачи, в том числе загрузки на паузе.
- Если окно осталось скрытым, Videoport закроется после завершения фоновых задач.

## Videoport 4.7.0 для Windows 11 x64

Скачайте установщик и выберите прежнюю папку Videoport, если обновляете программу. Установщик сохраняет проекты, модели и историю.

- **Транскрибация** обрабатывает местные аудио- и видеофайлы частями с сохранением прогресса. Доступны редактор реплик, разметка говорящих, перевод и экспорт в TXT, SRT, VTT, CSV, DOCX и PDF.
- **Сценарии** добавляют локальный чат с Qwen, сценарии для коротких и длинных роликов и раскадровки с референсами. Учитываются публичные рекомендации площадок и материалы по визуальному сторителлингу.
- **Обновления** в шапке приложения проверяют версию, скачивают официальный установщик и проверяют SHA-256 перед запуском.

# Videoport

Скачивайте свои видео и обложки с YouTube в папку на компьютере. Можно вставить несколько ссылок, настроить разрешение каждого ролика и запустить пакетную выгрузку для дальнейшей публикации в Рутубе, Дзене и ВК.

- Обычные ссылки, Shorts и записи завершённых эфиров.
- Разрешения из списка YouTube, включая вертикальное видео, 4K или 8K при наличии.
- MP4 с H.264 и AAC для публикации. Совместимые дорожки копируются, остальные перекодируются через FFmpeg.
- MKV по умолчанию с исходными дорожками без перекодирования.
- Обложки отдельно или вместе с видео. Сохраняется исходный формат изображения.
- Заголовок ролика используется как имя файла. Запрещённые символы удаляются, слишком длинные имена сокращаются, системные имена Windows получают префикс `_`. При совпадении имён добавляется номер.

## Windows 11

Распакуйте портативный ZIP для Windows 11 x64 целиком и откройте `Videoport.exe` внутри папки. Программа откроет своё окно. Вставьте ссылку, нажмите **Найти видео**, выберите разрешение и нажмите **Скачать видео** или **Скачать обложку**.

Готовые файлы сохраняются в папке `Загрузки\Videoport`. Кнопка **Открыть папку загрузок** открывает её в Проводнике. Для нескольких ссылок используйте **Пакетная загрузка**.

В ZIP входят Python, FFmpeg, Node.js и зависимости. Окно использует Microsoft Edge WebView2, который поставляется с Windows 11.

### Каналы, профили и очереди

- **YouTube:** вставьте ссылку на канал или отдельный ролик. Каталог разделяет длинные видео и Shorts. Записи завершённых эфиров входят в длинные видео. Приложение запрашивает разрешения каждого ролика и по умолчанию выбирает самое высокое из полученных.
- **Instagram:** вставьте ссылку на рилс, сторис, хайлайт или профиль. Для каталога постов, рилсов, актуальных сторис и хайлайтов из профиля войдите в Instagram в Firefox и включите **Использовать вход из Firefox** на вкладке. Материалы доступны в пределах прав этой учётной записи.
- **TikTok:** вставьте ссылку на профиль или отдельное видео.

В списке отметьте нужные материалы. В YouTube варианты качества запрашиваются автоматически. На других площадках кнопка **Показать варианты** запрашивает точные разрешения, когда они доступны. Нижняя панель **Скачать все** выгружает текущий список, а **Скачать выбранные** — отмеченные строки. Через **Выбрать папку** можно сохранить отдельный путь для каждой площадки.

### Окно загрузок

Нажмите **Загрузки** вверху окна. Оттуда можно приостановить, возобновить или отменить задачу, пока программа запущена. При отмене очищаются временные файлы. Готовый файл и папку можно открыть из журнала, а история загруженных файлов сохраняется между запусками.

У каждой задачи показан текущий этап. При наличии оценки отображается оставшееся время этапа. На этапе объединения видео и звука в MKV дорожки сохраняются без перекодирования.

## Локальный запуск

Установите [Python 3.10+](https://www.python.org/downloads/), [FFmpeg](https://ffmpeg.org/download.html) с FFprobe и libx264, а также [Node.js 22+](https://nodejs.org/en/download) или [Deno 2.3+](https://deno.com/). Команды `ffmpeg`, `ffprobe` и выбранная среда JavaScript должны быть доступны в терминале.

```sh
git clone https://github.com/Poklontsevv/downloader.git
cd downloader
python -m venv .venv
```

Активируйте окружение. На macOS и Linux используйте `source .venv/bin/activate`, в Windows PowerShell — `.\.venv\Scripts\Activate.ps1`. Если в вашей системе Python запускается как `python3` или `py`, используйте эту команду для создания окружения.

```sh
python -m pip install -r requirements.txt
python -m videoport
```

Откройте [локальный интерфейс](http://127.0.0.1:8765). Вставьте ссылки по одной на строку, выберите разрешения и нажмите **Скачать выбранные**. Обложку можно скачать кнопкой на карточке ролика или у всех выбранных роликов сразу. Файлы появятся в папке `downloads`. Очередь сохраняется до остановки программы.

Параметры запуска:

```sh
python -m videoport --output "./exports"
python -m videoport --js-runtime deno
python -m videoport --browser firefox
```

Для закрытых видео запустите Videoport с `--browser` и укажите браузер, в котором открыт YouTube под аккаунтом с доступом к ролику. При ошибке чтения профиля закройте браузер и повторите попытку. Можно использовать локальную страницу Videoport в другом браузере. Хромиум-браузеры в некоторых конфигурациях шифруют cookies и ограничивают их чтение, в этом случае подойдёт Firefox с открытым сеансом YouTube.

## GitHub Pages

Откройте [Videoport на GitHub Pages](https://poklontsevv.github.io/downloader/) и запустите загрузчик на том же компьютере:

```sh
python -m videoport --allow-pages
```

Нажмите **Подключить** и разрешите браузеру доступ к локальной сети, если он запросит разрешение. GitHub Pages обслуживает интерфейс, а yt-dlp и FFmpeg работают локально. Если браузер блокирует подключение страницы к локальной сети, откройте [локальный интерфейс](http://127.0.0.1:8765).

## Доступность видео

Качество зависит от дорожек, которые YouTube отдаёт для ролика. Обновляйте yt-dlp, если YouTube поменял способ выдачи видео.

```sh
python -m pip install -U -r requirements.txt
```

### Установка и обновление Windows

Запустите `Videoport-Setup-x64.exe`. Выберите папку на экране «Папка установки». Установщик скачает Qwen и движок llama.cpp (около 1,15 ГБ) в подпапку `models` и создаст ярлык в меню «Пуск». Для первой установки нужен интернет. Для обновления закройте Videoport и дождитесь фоновых задач, затем запустите установщик новой версии. Установщик предложит прежнюю папку, обновит ярлык и повторно использует проверенные модели. Настройки, история, скачанные видео и экспортированные клипы сохранятся. Удаление программы доступно в параметрах Windows.

### Нарезка

Вкладка **Нарезка** работает в приложении Windows. Выберите локальное видео или готовый файл из загрузок. Whisper распознаёт речь и строит таймкоды, а анализ кадров отмечает движение и смены сцен. С включённым Qwen программа подбирает связанные реплики из разных мест записи. Когда речь не распознана, программа может соединить моменты движения в одной сцене и убрать паузы между ними. В поле **Задание для Qwen** можно описать, какие сцены или темы искать. С заданием модель оценивает и спокойные, и динамичные фрагменты по тексту и интенсивности движения. Задание сохраняется в проекте.

Нажмите **Редактировать** у клипа. В редакторе сразу открывается воспроизведение по текущему монтажу. На таймлайне видны все отрезки монтажа. Нажмите на линейку для перемотки, потяните за края блока для подрезки или перетащите блок для смены порядка. Кнопка «Разделить» делает разрез по курсору. Новые отрезки добавляются по таймкодам или из расшифровки.

Во вкладке **Кадр** переключайте 9:16 и 16:9 в любой момент. Формат меняется в превью и при экспорте, а монтаж, текст и оформление субтитров сохраняются. В режиме заполнения кадра можно включить слежение за лицом, движением или объектом, указанным в предпросмотре. При первом запуске слежения загружаются OpenCV и NumPy (52 МБ). Траектория сохраняется в проекте и повторно используется при переключении формата или слежения. Смена объекта или исходных отрезков может потребовать нового анализа.

На дорожке **Субтитры** можно редактировать текст и таймкоды, добавлять, делить, объединять и удалять блоки. Показ настраивается по одному, два или три слова, в две строки или целыми репликами. Доступны шрифты, цвет, размер, положение, обводка, тень и подложка. Вариант Blocks использует открытый Unbounded с кириллицей. Можно добавить свой TTF или OTF. В разделе **Распознавание** доступны восстановление автосубтитров текущего видеоотрезка и сохранение SRT в папку клипов проекта.

Проект создаётся при запуске анализа. Монтаж, субтитры, расшифровка и экспортированные MP4 1080 × 1920 или 1920 × 1080 хранятся в папке `Projects` рядом с программой. Там можно открыть проект после перезапуска или повторить прерванный анализ. Исходное видео остаётся на своём месте. Для дополнительных копий выберите отдельную папку экспорта.

При первом анализе программа скачивает выбранную модель Whisper. По умолчанию используется Large-v3 Turbo (574 МБ). Также доступны Medium (539 МБ) и Small (190 МБ). Для тихой речи звук усиливается перед распознаванием. В сохранённом проекте откройте клип и нажмите «Распознать заново», чтобы обновить автосубтитры для выбранных отрезков с сохранением ручных правок. В версии без установки Qwen и движок llama.cpp (~1,15 ГБ) скачиваются при включении смыслового монтажа. Видео и речь обрабатываются локально.

- Распознавание: [whisper.cpp](https://github.com/ggml-org/whisper.cpp)
- Смысловая оценка: [Qwen2.5-1.5B-Instruct-GGUF](https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct-GGUF) и [llama.cpp](https://github.com/ggml-org/llama.cpp)

В Windows режим **Авто** проверяет драйвер NVIDIA и свободную видеопамять. При первом подходящем запуске Videoport скачивает проверенные библиотеки CUDA и cuBLAS (482 МБ суммарно). Для GTX 1050 нужен совместимый драйвер NVIDIA версии 522.06 или новее. При сбое обработка продолжится на процессоре с той же моделью. В редакторе можно выбрать модель и устройство отдельно для повторного распознавания клипа. По окончании Videoport показывает устройство и время распознавания.


### Транскрибация

Откройте **Транскрибация**, выберите несколько аудио- и видеофайлов либо готовые записи из загрузок. Длинная запись обрабатывается двухминутными частями. Каждая часть сохраняется в библиотеке рядом с программой, пауза и отмена срабатывают после текущего вычисления. После прерывания нажмите **Продолжить**. Ограничения на длительность записи в приложении нет.

Можно усилить тихую речь, включить разметку говорящих и выбрать язык и модель Whisper. В редакторе доступны поиск, замена, плеер с переходом по времени, изменение текста и таймкодов, добавление, разделение и объединение реплик. Разметку говорящих можно переименовать и поправить. Автоматическая разметка сопоставляет голосовые признаки реплик; результат стоит проверить, особенно где голоса перебивают друг друга. Перевод во время распознавания на английский поддерживают Whisper Small и Medium. Готовую расшифровку можно перевести на один из 12 языков локальным Qwen. Перевод сохраняется как отдельная запись. Экспортируйте одну или несколько записей в TXT, SRT, VTT, CSV, DOCX или PDF.

### Сценарии

Во вкладке **Сценарии** задайте тему, длительность, формат, площадку и аудиторию. Qwen пишет текст для съёмки и принимает уточнения в чате. Для длинных роликов сценарий пишется по главам. Из текста можно собрать редактируемую раскадровку с таймкодами, масштабом, движением камеры, озвучкой, надписями и промптами. Изображения-референсы добавляются из своих файлов. Экспорт сценария — TXT, раскадровки с изображениями — автономная HTML-страница.

Раздел **Источники** показывает используемые справочные материалы. Videoport подбирает выжимки из рекомендаций площадок и материалов по визуальному сторителлингу по выбранному формату и площадке. При желании добавьте к проекту заметки автора из TXT или Markdown. Чаты, сценарии и кадры сохраняются в папке `Projects/Scripts`.

### Проверка обновлений

В шапке программы нажмите **Обновления**. Videoport проверяет официальный релиз GitHub, скачивает EXE и сравнивает его SHA-256 с опубликованным значением. Нажмите **Установить обновление**, дождитесь фоновых задач и завершите установку в прежнюю папку. Данные и модели лежат в папках рядом с версионными сборками.

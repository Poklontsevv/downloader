## Videoport 4.8.1 для Windows 11 x64

Запустите установщик и выберите прежнюю папку Videoport для обновления.

- Субтитры выбранного клипа можно сгенерировать заново и отменить замену в редакторе.
- Чат сохраняет пронумерованные версии сценариев. Полный текст открывается из сообщения.
- Раскадровки создаются автоматически или вручную из выделений в сценарии, в стилях скетча и реализма. Кадры можно перегенерировать.
- Разделы занимают ширину окна. Масштаб таймлайна меняется колёсиком и кнопками плюс и минус.

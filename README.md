## Videoport 4.9.0 для Windows 11 x64

Запустите установщик и выберите прежнюю папку Videoport для обновления.

- Светлый и тёмный интерфейс для загрузок, нарезки, редактора, транскрибации и сценариев.
- В транскрибации можно переключаться между списком реплик с таймкодами и полным текстом.
- До анализа можно выбрать цельные фрагменты или монтаж из связанных частей записи.
- Для каждого видеоотрезка сохраняются свои положение, масштаб, размытие фона, кадрирование и оформление субтитров.
